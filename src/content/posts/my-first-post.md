## 欢迎来到我的博客

这是我在 GitHub Pages 上搭建的第一个博客。选择使用 Astro + Tailwind CSS 的组合，主要是因为：

- **Astro** 生成纯静态网站，加载速度极快
- **Tailwind CSS** 让样式开发变得高效
- **GitHub Pages** 免费且稳定

### 为什么写博客？

1. 记录生活中的点滴
2. 分享技术学习心得
3. 与更多人交流想法
4. 配合我的 [心之旅途](https://github.com/vectrol/xin-zhi-lu-tu) 项目，记录心理学自学的历程
